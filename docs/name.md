# The ADHD Duck name

ADHD Duck is the name of this fork of Angry Duck. The public project name is
**ADHD Duck**, the GitHub repository is `sysmrk/Adhd-Duck`, and the technical
prefix used by binaries, Kubernetes resources and metrics is `adhdduck`.
Container images use the `adhd-duck-` prefix.

The rename establishes the fork's identity. It does not change the tool's
purpose: managing container images on Kubernetes nodes through preheating,
peer distribution, rescue, repair, caching and garbage collection.

The original naming story belongs to the upstream project and remains
available in [its documentation](https://github.com/hatam-abolghasemi/Angry-Duck/blob/5102a56b8037bce1b249d2e3bbfcd32e55f66d8f/docs/name.md).
See [NOTICE](../NOTICE) for attribution and [migration](migration.md) for
the operational implications of the new names.
